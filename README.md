# 小米手环 6 心率桌面监控

这个程序通过 Windows 蓝牙监听用户选择的目标设备
发出的心率广播，并显示在桌面窗口中。它不连接手环，也不向手环写入 GATT
特征值，因此不需要写权限。

界面使用 `sv-ttk`，默认采用暗色主题，可点击“切换主题”在暗色和亮色之间切换。
主窗口默认尺寸已加大，并支持手动调整大小；较长的设备名称、状态信息和样式控件会
随窗口空间布局，不再固定裁切。

主界面中的“显示悬浮窗”会打开一个可拖动、置顶的桌面窗口，显示当前 BPM 和 MC 风格
像素心脏。悬浮窗样式可以在主界面中调整：

悬浮窗设置默认折叠，点击“展开悬浮窗设置”后显示全部样式选项。

- 数字格式，例如 `{bpm} BPM`、`心率 {bpm}`；其中 `{bpm}` 会替换为当前数值；
- 图标选择：MC心脏（Minecraft 原版贴图）、像素心脏、文字心脏、自定义图片或无图标；
- MC心脏使用随程序附带的 `mc_heart.png`（Faithful 32x 资源包的官方高清重绘版
  心脏，18×18），按整数倍最近邻缩放，任意大小都保持像素锐利；
- 可分别调整图标大小和心率数字字号，并从系统字体列表选择数字字体；
- 自定义图标支持 PNG、GIF、PPM 和 PGM 图片，导入后可通过图标大小控制缩放；
- 数字颜色、心脏颜色、背景颜色；
- 背景透明度和内容透明度分别调节，背景变淡不会让数字和心脏一起变淡；
- 可选开启“实时心率折线”：悬浮窗底部跟随最近 120 个样本的迷你曲线（含
  区间参考线与最新值光点），窗口自动加高；
- 可选开启“动态最高/最低值”：右上角实时显示本次采样的最低与最高 BPM；
- 可选开启“心脏跳动动画”：心脏按真实心率频率做 lub-dub 双搏动缩放（第一次
  收缩 1.12×、第二次 1.18×，余弦缓动，周期 = 60/BPM 秒），每次收到新样本自动
  重新对齐相位；停止收样 5 秒后降级为缓慢呼吸微动。动画只作用于心脏，
  数字与曲线不受影响，关闭时零开销；
- 悬浮窗固定使用无边框分层模式，避免 Tk 原生客户区造成白屏；仍可直接拖动悬浮窗。

悬浮窗使用 Windows 分层窗口绘制，背景透明度和内容透明度独立控制；悬浮窗不会启动
额外的 WebView GUI 循环，因此不会和主界面的 Tk 主循环互相阻塞。字体使用系统字体，
中文字体（如微软雅黑、宋体）可直接生效；自定义图标使用 Pillow 加载。

悬浮窗会根据数字格式和图标自动调整尺寸；例如较长的 `心率：{bpm} BPM` 格式会
自动扩展宽度，无图标模式会自动缩短高度。

心脏和数字分别提供 X/Y 滑杆，可自由定位；窗口会随坐标自动扩大。像素心脏采用
Minecraft HUD 常见的 8×9 像素轮廓绘制；想要原版观感请选 MC心脏，它直接使用
Minecraft 的血量贴图。

样式修改会立即同步到悬浮窗。关闭悬浮窗不会停止心率采集，悬浮窗可再次打开。

## 统计专区

每次点击“停止”结束一次采集后，会自动弹出“心率统计”窗口（要求本次至少收到一个
有效样本）：

- **统计量**页：样本数、时长、均值、中位数、众数、最小/最大值、极差、方差、
  样本/总体标准差、Q1/Q3 四分位数、心率区间分布（静息 ≤60 / 正常 61-99 /
  偏高 ≥100 的样本计数）；
- **折线图**页：BPM 随时间变化的完整曲线；
- **散点图**页：原始采样散点（无连线），点色随时间由蓝渐变到红以展示时段漂移，
  附中位数虚线与最小/最大值标注；
- **柱状图**页：BPM 分布直方图（每个出现过的值一根柱）；
- **K线图**页：股票式 OHLC 蜡烛图，按时间自动分桶（约 10-40 根），红蜡烛 =
  收盘 ≥ 开盘（心率上行），绿空心蜡烛 = 收盘 < 开盘（心率下行），可直观看出
  心率的“涨跌”区间和波动幅度；
- **导出 Excel**：生成 `.xlsx`，包含三个工作表——原始时间序列（时间+BPM）、
  统计量数值表、以图片形式嵌入的全部图表（含 K 线图）；
- **导出 CSV**：仅原始时间序列，UTF-8 BOM 编码，Excel 可直接打开。

## 多设备同时记录

勾选“多设备模式”后点“开始读取”，程序不再过滤单一 MAC，而是记录**所有**
发出小米心率广播（公司 ID `0x0157`）的设备，每台设备独立限流、独立会话。
停止后弹出多设备统计窗口：设备对比表（样本数/均值/最值/标准差）、每设备折线图
标签页，可导出汇总 xlsx（汇总表 + 每设备时间序列 + 嵌入图表）或单设备 CSV。

## 提醒阈值与配置持久化

- 主界面可设置“低于 / 高于”两个 BPM 阈值：采样值越界时状态栏警告并鸣音提示，
  30 秒最多触发一次（多设备模式下不生效，仅单设备模式）。
- MAC 历史、悬浮窗全部样式、提醒阈值会保存到
  `%APPDATA%\MiBandHeartRateMonitor\devices.json`，重启后自动恢复。

主窗口会根据悬浮窗设置面板当前是否展开，按照可见控件的实际请求尺寸自动调整，
不会在折叠状态保留设置面板造成的空白，也不会在展开状态截断设置项。

## 使用

1. 在 Windows 设置中打开蓝牙，确认手环在附近，并在手环上开启心率广播。
2. 在 PowerShell 中进入本目录，安装依赖：

   ```powershell
   py -m pip install -r requirements.txt
   ```

   依赖包含 `openpyxl`（统计导出 Excel 用）。

3. 运行：

   ```powershell
   py heart_rate_monitor.py
   ```

点击“开始读取”后，程序会监听指定地址的广播。窗口中可以修改：

- **手环 MAC 地址**：首次使用点击“扫描设备”，从周边设备列表中选择目标设备，
  MAC 会自动填入；也可以手动输入 `AA:BB:CC:DD:EE:FF`。
- **采样频率（Hz）**：程序最多以该频率更新一次心率，范围为 `0.1` 到 `100` Hz。
- **设备信息**：收到目标设备广播后显示设备名称、MAC 地址和 RSSI 信号强度。

修改配置后重新点击“开始读取”即可生效。

采样频率支持运行中实时修改：直接编辑输入框，停止输入约 0.3 秒后即可应用，
无需断开或重新开始扫描。MAC 地址仍需要重新点击“开始读取”后生效。

注意：采样频率是程序对收到的广播进行限流的上限，不会让手环产生更高频率的广播。
实际刷新速度仍由手环的心率广播频率和 Windows 蓝牙适配器决定。程序启动后会立即
开始监听，收到第一个有效广播就显示心率；如果手环本身每秒只广播一次，设置为
100 Hz 也不会超过每秒一次。

首次启动时程序会在后台线程扫描系统字体（构建中文名映射，约 1-4 秒，视字体数量
而定），期间悬浮窗数字先用回退字体，就绪后自动换装；映射缓存到
`%APPDATA%\MiBandHeartRateMonitor\font-cache.json`（以字体目录状态为指纹，装/
删字体后自动重建），之后的启动直接读缓存，毫秒级就绪。

为减少高频广播造成的界面排队延迟，设备信息最多每 0.5 秒更新一次，状态文字最多
每秒更新一次；BPM 数据不会因为这些辅助信息事件而排队阻塞。界面事件轮询间隔为
30 毫秒。

运行中可以点击“暂停采样”暂时停止 BPM 更新（蓝牙扫描仍保持运行），再点击“继续采样”
恢复；点击“停止”会关闭扫描，之后可以重新选择 MAC 地址并点击“开始读取”。

输入过的 MAC 地址会保存到 Windows 用户配置目录
`%APPDATA%\MiBandHeartRateMonitor\devices.json`，之后可以从下拉框选择，最多保存最近
20 个地址。

首次使用时程序不会预置任何设备 MAC。扫描列表包含名称、MAC 地址和信号强度，
请只选择自己的手环；扫描到的设备不会自动开始采集，必须选择后点击“开始读取”。

程序只会处理 MAC 地址完全等于输入值的设备。扫描到其他小米设备时会静默忽略，
不会采集其数据，也不会打断目标手环的心率刷新。如果目标手环始终没有数据，请确认
输入的是目标手环当前广播地址；不要把不属于手环的地址填入输入框。

## 注意事项

- Windows 通常会为 BLE 设备提供可用的 MAC 地址；如果扫描不到设备，请先在系统蓝牙设置中配对手环，并确认地址没有变化。
- 程序读取小米广播厂商数据（公司 ID `0x0157`）中的心率字段；请勿把它改回 GATT 连接/通知方式，否则可能出现“无写权限”。
- 标准心率广播的测量值为 BPM。未佩戴时手环可能确实广播 `0`，程序会如实显示，不会推断或修正该值。
- 这个程序只读取心率，不是医疗设备，不能用于诊断或紧急监测。
